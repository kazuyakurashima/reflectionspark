# ダミー台本の目安（数字と言葉の型だけ）

- **何の文書か**：評価とデモのダミー面談を、本物の面談に近い形で書くための目安。台本（`eval/cases/*/script.txt`）を書くときに読む。
- **出どころ**：作り手の面談の振り返りの記録から、数字と言葉の型だけを取り出した。
- **書かないもの**：面談の中身（学年・家族の構成・時期・成績・相手の言葉・出来事）。特定の 1 回をなぞった台本にしない。
- **使い方**：型を全部入れない。1 本に 2〜3 個まで。保護者面談・コーチング・ひっかけは、一般的な形を主にし、型は 1〜2 個にとどめる（評価が一人の癖に寄らないように）。

## 1. 話しすぎの形

数字（目安）：

- 望ましいとされる目安は「講師 4 割以下・相手 6 割以上」。話しすぎの回はこれが逆転する（講師 6〜7 割。推定）。
- 講師のほぼ一方通行の区間が、面談全体の約 3 割を占めた回がある（約 8 分半の面談で約 2 分半）。
- 1 回の長い独演より、次の形が多い。

| 形 | 台本での書き方 |
|---|---|
| ① 相手が相槌だけの中で、説明が続く | 相手が問いを一つに絞ったのに、講師の答えが構造 → 見通し → 模試や講習の案内まで広がる（聞かれた以上に答える）。相手は「はい」「うん」だけ |
| ② 自分の問いに、自分で解説を重ねる | 講師が相手に考えさせる問いを立てるが、答えを待たずに例や体験談を足す。問いの言い直しが長い。相手が考え始めた所に補足を入れる。最後に講師が「私ばっかり話しちゃったね」と言う |
| ③ 決まった後に説明を足す | 相手が決めた後に、通い方や手続きの説明を厚くする |

- 話しすぎが常に悪いとは限らない。情報を求める相手には歓迎される。話の中身が「相手の矛盾を返す踏み込み」なら、話す量が多くても点は高くなりうる（設計書の決まり 5：量だけで良し悪しを決めない）。

## 2. 言うべきことの代わりに出る言葉

どれも「角が立たない、正しい言葉」。言いにくいことを言って相手の反応を待つ代わりに、正しい言葉を足す。話しすぎと言えなさは、同じ所から出る。

| 型 | 台本での書き方（作った例） |
|---|---|
| 遠回しなほのめかし | 「苦手な科目があると、選べる道が少し狭くなるんだよね」と一般の話として言い、相手のことだとは言わない |
| 一般論 | 「この時期の子は、集団のほうが緩まずにやれることが多いですね」 |
| 相手の考えや選択を肯定して、そこで止める | 相手の迷いや不安に「それもいい選択ですね」と返し、問い返さない |
| 家庭へのお願い | 塾が主導して決めるべき所で、「おうちでも声をかけてもらえると」と頼む |
| 決定権のない子どもに向けて話す | 保護者に言うべきこと（枠組みを親が決める場面だ、など）を、同席の子どもに「先生だったら〜する」と言う |
| 深くて正しい説明 | 相手の決めごとを整理する代わりに、仕組みや本質の説明を丁寧にする |
| 先に延ばす | 「まずは模試を受けてみよう」「そこは夏にやろう」と、次の機会の案内で着地する |
| 励まし | 見立てを言う代わりに「大丈夫、これからだよ」と言う |

## 3. 相手の返事の変化

衝突は起きない。代わりに、次のように変わり、決めないまま終わる。その場では「うまくいった」と感じやすく、本人の自己採点が分析より高くなりやすい（言わなかったこと自体に気づかないため）。

| 変化 | 台本での書き方 |
|---|---|
| 同じ訴えの繰り返し | 相手が同じ困りごと（家では勉強しない、時間帯が合わない、など）を、言い方を変えて 3〜4 回言う。決めるためのサインを何度も出す |
| 短い相槌・「はい」 | 説明の間は「はい」だけ。最後は「検討します」「考えてみます」で持ち帰る |
| 定型的な答え・問いの周辺だけ答える | 「成績を上げたいです」と即答する。問いの核心を外して周辺だけ答える |
| 相手同士で話が進む・委ねる言葉で守る | 保護者どうしの相談に流れる。「本人次第なので」をくり返す |
| 穏やかに順調に終わる | 円満に終わるが、相手が自分から言った不安が回収されないまま残る |

## 4. 踏み込んだときとの対比

- **本音を許してから聞く**：「率直でいいよ」と言ってから聞くと、相手が条件つきの本音を話す（「少しならできるけど、言われただけだと続かない」の形）。
- **矛盾を返す**：相手の望みと今の行動の差を、そのまま返して「その差、どう思う？」と聞く。相手の答えが、否定から条件つきの前向きな言葉へ、自分の言葉で動く。
- **直接確かめる**：「引っかかっているのは〇〇ですか」と本当の障害を直接聞くと、反対ではないことが分かる。
- 台本では、踏み込んだ後に相手の発話が長くなり、相手が自分の言葉で話し始める。

## 5. 山場の 2 本への当てはめ

- **1 回目**：次に試せる所（「大丈夫、これからだよ」）の後に、講師が講習や日程の説明を足し、生徒は短い返事だけになる区間を置く（話しすぎ①と励ましが同じ場面でつながる）。この区間を全体の 2〜3 割にする。次に試せる所の発話番号は変えない。
- **2 回目**：前半は講師が長めに話してよい（本人は「話しすぎた」と自分の点を下げる）。その中の短い 1 行で矛盾を返し（「行きたいんだよね。でも、家での勉強はゼロ。この差、どう思う？」）、その後は生徒の返事が長くなり、自分の言葉で決める。AI の点が自己評価より高くなる形。
- 評価の「山場の検査」では、AI が選んだ場面を記録し、作り手の判定と重なったかを見る。合格線にはしない（`docs/設計書.md`「評価で見ること」）。
