# 画面のモック（比較用）

本体（`app/`）とは独立した、静的な HTML のモック。API は呼ばず、ダミーデータ（`eval/cases/student-shinro`）の保存済みの分析結果を埋め込んでいる。本体の画面 1〜5、評価エンジン、記録係・夢には影響しない。

| ファイル | 何か |
|---|---|
| `d2-simple.html` | 画面 2「読む」の比較モック **D2 Simple**。D2 の思想（本人の見立てと AI の見立てを照合する）を、D1 の少ない要素で実現する案 |
| `d2-simple-比較.md` | 既存 D2・本体の画面 2 との比較（削除した要素、操作数、改善点、失われた機能）と、確かめたこと |
| `screenshots/` | デスクトップ（1280px）と iPhone 13 の幅で撮った初期表示と開いた状態 |

## 開き方

ファイルをそのままブラウザで開く（サーバーは要らない）。

```bash
open mocks/d2-simple.html
```

書いた「自分の見立て」と「自分の点」はブラウザの localStorage にだけ残る。消すときは、ブラウザのサイトデータを消すか、開発者ツールで `localStorage.clear()` を実行する。

## データについて

- 発話 132 件は `eval/results/runs/student-shinro/step0.json`（工程 0 の後の発話）から、発話番号・話者・本文だけを写した。
- 場面・問い・観察・読み・点は `step1.json`・`step2.json` の AI の出力をそのまま使った。観察の文の中の引用には、元の出力で外されていた「」を読みやすさのために付け直し、古い発話番号の書き方「1-n」は今の「発話 n」に直した。
- 面談の地図の章の見出し（「部活」「進路と志望校」など）は、工程 1 の「面談の流れ」の文を手で短くしたもの。本番ではアプリが作るか、工程 1 に短い見出しを返させる必要がある。
- 面談名の「初回」「進路」と日付は仮。
- 引用の照合（cited_text と発話の本文の完全一致）はモックの中でも行い、一致した引用だけを出している。
